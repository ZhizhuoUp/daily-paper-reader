## 摘要
长程机器人规划需要对语义任务结构和几何可行性进行联合推理。为了成功执行任务，机器人必须分解目标、选择与任务相关的物体并对动作进行排序，同时确保规划满足诸如有限空闲空间和物体碰撞等空间约束。在这项工作中，我们提出了 APIVOT，这是一种基于视觉语言模型（VLM）的规划器，它在长程规划中自适应地交织语言和视觉思维。APIVOT 学习利用语言进行语义推理，同时将视觉思维作为想象的未来状态，用于几何可行性的内部验证。在长程厨房任务中，APIVOT 的表现优于通用 VLM 和先前的规划框架，在空间受限的设置中取得了最大的提升。我们发现 APIVOT 学习到了有意义的模态选择行为，证明了视觉-语言思维的自适应交织提高了规划成功率和推理效率。

## Abstract
Long-horizon robot planning requires jointly reasoning over semantic task structure and geometric feasibility. To successfully execute a task, a robot must decompose goals, select task-relevant objects, and sequence actions, while ensuring that plans satisfy spatial constraints such as limited free space and object collisions. In this work, we propose APIVOT, a VLM-based planner that adaptively interleaves language and visual thoughts for long-horizon planning. APIVOT learns to leverage language for semantic reasoning, while using visual thoughts as imagined future states for internal verification of geometric feasibility. On long-horizon kitchen tasks, APIVOT outperforms general-purpose VLMs and prior planning frameworks, achieving the largest gains in spatially constrained settings. We find that APIVOT learns meaningful modality selection behavior, demonstrating that adaptive interleaving of vision-language thoughts improves both planning success and reasoning efficiency.

长程机器人规划（Long-horizon planning）要求同时具备**语义推理**（如任务分解、物体选择）和**几何可行性推理**（如空间是否足够、是否会发生碰撞）。
*   **研究动机**：现有的基于大语言模型（LLM）或视觉语言模型（VLM）的规划器虽然能生成语义上合理的动作序列，但在处理复杂的几何约束时经常失败。
*   **核心挑战**：现有的改进方法通常依赖外部验证器或重规划机制，几何信息并未进入模型内部的推理过程。
*   **论文目标**：提出一种能将语言和“视觉思维”（Visual Thoughts）自适应交织的规划器，使模型在生成计划前，能通过“想象”未来的视觉状态来验证几何可行性。

### 2. 方法论：核心思想与关键技术
APIVOT 的核心思想是在推理链（Reasoning Trace）中引入**潜空间视觉表示**作为中间步骤。
*   **视觉思维（Visual Thoughts）**：在自适应推理过程中，模型会生成一段固定长度的视觉 Token。这些 Token 的隐藏状态（Latent Visual State）被对齐到编码后的未来真实场景图像。
*   **三阶段训练课程（Curriculum Training）**：
    1.  **视觉理解阶段**：提供真实的未来视觉特征，训练模型学习如何利用这些视觉信息来指导后续规划。
    2.  **视觉生成阶段**：训练模型自主生成这些潜空间视觉状态，通过余弦相似度损失（Cosine Similarity Loss）将其与真实未来图像的特征对齐。
    3.  **自适应模态选择阶段**：通过监督微调（SFT），让模型学习在何时使用纯文本推理（简单语义任务），何时引入视觉思维（空间受限或需验证几何可行性的任务）。
*   **损失函数**：结合了动作计划的交叉熵损失（$L_{CE,plan}$）、推理链的交叉熵损失（$L_{CE,trace}$）以及视觉对齐损失（$L_{vis}$）。

### 6. 主要结论与发现

*   **高效性**：通过自适应选择模态，APIVOT 在仅损失 9% 性能的情况下，减少了 **39% 的 Token 使用量**。
*   **泛化能力**：在未见过的组合任务上依然保持了领先优势。

### 7. 优点
*   **内部化几何推理**：将几何验证从外部模块引入模型内部的推理链，使规划更具前瞻性。
*   **自适应机制**：模型学会了“按需思考”，在简单步骤使用廉价的文本，在关键步骤使用昂贵的视觉想象，平衡了性能与成本。
*   **紧凑表示**：相比于冗长的文本描述，潜空间视觉 Token 能更高效地编码复杂的空间布局。

### 8. 不足与局限
*   **模拟器依赖**：实验完全在 KitchenWorlds 模拟器中进行，尚未在真实世界机器人或高度写实的渲染环境中验证。

*   **监督信号来源**：自适应选择的标签依赖于模拟器的几何启发式算法，如果启发式算法本身有偏差，可能会限制模型的上限。
