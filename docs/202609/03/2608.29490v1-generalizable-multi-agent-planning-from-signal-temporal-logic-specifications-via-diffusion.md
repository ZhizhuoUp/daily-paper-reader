## 摘要
现实世界中的多智能体系统（如无人机群、自动驾驶汽车、仓库机器人）必须在避免碰撞的同时满足丰富的时序任务。信号时序逻辑（STL）能够优雅地编码此类目标，但现有的 STL 规划方法面临着关键局限。最先进的基于优化的方法可以处理任意 STL 规约，但难以兼顾可扩展性，随着智能体数量的增加，在计算上变得不可行。基于学习的方法能够以快速的规划时间高效处理大量智能体，但当部署时的目标与训练时的目标不同时表现较差，且不支持需要为不同智能体指定不同规约（即异构性）的规划任务，或需要多个智能体协调的团队级规约。这种泛化性与可扩展性之间的根本权衡，为在实践中实现多智能体 STL 规划算法带来了挑战。为克服这一挑战，我们提出了一种用于带有 STL 规约的多智能体规划的新型扩散方法。利用 STL 的可微近似，我们在去噪过程中集成了 STL 梯度，使我们的方法能够泛化到谓词放置在训练期间覆盖的目标区域内任意位置的新公式，同时实现与现有基于学习的方法相同的可扩展性。我们的方法支持异构规约，并且通过使用扩散模型，自然地增强了规划的多样性，从而显著减少了智能体之间与安全相关的违规行为（如碰撞）。详细的评估研究证明了基于 STL 引导的扩散多智能体规划器在构建可泛化、可扩展和多样化规划方面的实用性。视频和代码可在 https://www.jeappen.com/diff-ma-stl/ 和 https://github.com/jeappen/diff-ma-stl 获取。

## Abstract
Multi-agent systems in the real-world (e.g., drone swarms, autonomous cars, warehouse robots) must satisfy rich, temporal tasks while avoiding collisions. Signal Temporal Logic (STL) elegantly encodes such objectives, but current STL planning methods face critical limitations. State-of-the-art optimization-based approaches can handle arbitrary STL specifications but struggle with scalability, becoming computationally impractical as the number of agents grows. Learning-based methods efficiently handle a large number of agents with rapid planning times but fare poorly when deployment-time objectives differ from those used during training, and do not support planning tasks that require different specifications to be ascribed to different agents (i.e., heterogeneity) or team-level specifications requiring coordination of multiple agents. This fundamental trade-off between generalizability and scalability presents a challenge for realizing multi-agent STL planning algorithms in practice. To overcome this challenge, we introduce a new diffusion method for multi-agent planning with STL specifications. Using a differentiable approximation of STL, we integrate the STL gradient in the denoising process, making our approach generalizable to novel formulas whose predicates are placed anywhere within the goal region covered during training, while achieving the same scalability as existing learning-based methods. Our method supports heterogeneous specifications, and by using diffusion models, naturally enhances plan diversity, thereby significantly reducing safety-related violations (e.g., collisions) among agents. A detailed evaluation study justifies the utility of STL-guided diffusion-based multi-agent planners for constructing generalizable, scalable, and diverse plans. Videos and code are available at https://www.jeappen.com/diff-ma-stl/ and https://github.com/jeappen/diff-ma-stl .

### 2. 论文提出的方法论

#### 核心思想
提出 **DIFF-MA** 框架：将多智能体轨迹生成转化为**基于扩散模型的引导采样问题**。关键创新在于**仅在单智能体无标签轨迹数据上进行离线训练**，在测试阶段通过可微 STL 梯度与多智能体交互/可达性损失，联合引导多智能体轨迹在去噪过程中收敛至安全、合规的规划。

#### 关键技术细节与算法流程
1.  **离线扩散模型训练（单智能体）**：
    *   采用 EDM（Elucidating Diffusion Models）架构，仅在单智能体覆盖设定区域谓词（Predicates）的轨迹集上训练一个 U-Net 去噪器 $D_\theta$。
    *   避免了训练期对多智能体复杂交互的硬编码，极大降低了训练成本。
2.  **测试期 STL 与可达性引导去噪（Joint MA Guidance）**：
    *   在去噪步骤 $n$ 中，计算引导函数 $f_{\text{guid}} = -\lambda_{\text{STL}} L_{\text{STL}} - \lambda_{\text{ach}} L_{\text{ach}}$。
    *   **STL 损失 $L_{\text{STL}}$**：利用可微 STL 鲁棒性语义，计算去噪目标轨迹 $\tilde{\tau}^g$ 的鲁棒性得分得分负值，通过反向传播获取梯度 $\nabla_{\tilde{\tau}^g} f_{\text{guid}}$ 调整去噪方向。
    *   **可达性损失 $L_{\text{ach}}$**：为确保生成的轨迹符合底层动力学并考虑智能体间避障，将去噪轨迹与基于图控制屏障函数（GCBF+）控制器闭环模拟的轨迹进行对比，引入误差损失，在去噪后期（最后 20% 步骤）进行纠偏。
3.  **重采样与检验机制（Resampling & Monotonicity）**：
    *   在推理阶段针对每个智能体执行最多 $N_{\text{sample}}$ 次（如 40 次）平行批量采样（Batch=8），保留 STL 鲁棒性得分最高且满足 $\rho(\phi_i, \tau^g_i) > 0$ 的轨迹。一旦某智能体轨迹达标即予以冻结，确保决策收敛。
4.  **底层安全控制**：
    *   高层由 DIFF-MA 输出目标点序列，低层分布式执行由 GCBF+（Neural Graph Control Barrier Function）控制器实施实时防碰撞。

### 6. 论文的主要结论与发现

1.  **可扩展性与成功率**：在拥堵的 $N=32$ 大规模异构场景中，DIFF-MA 达到了 84% 以上的综合成功率，相对最强 Baseline（STLPY-SA）**成功率提高了 36%**，规划速度提升了 **55 倍**。

3.  **轨迹多样性与避障优势**：扩散模型的生成多样性使智能体轨迹自然分散（Path Overlap 接近 0%），极大缓解了密集集群中的拥堵死锁。DIFF-MA 在 $N=32$ 时的碰撞失效比例（10.9%）远低于 STLPY-SA（34.4%）和 DIFF-SA（27.5%）。
4.  **团队协作（CaTL+）解耦**：在带有冗余和团队避障的 CaTL+ 任务中，DIFF-MA 无需显式的“任务-智能体分配”算法即可实现隐式高效协作，成功率比基于 Oracle 分配的 STLPY-SA 高出 30% 以上。

### 8. 不足与局限

*   **极高密度场景的物理局限**：在限定尺寸地图扩展至 $N=128$ 时，由于底层 GCBF+ 安全屏障在极度拥堵时容易引发局部死锁，成功率降至 42%（与 STLPY-SA 相当）。
*   **依赖精确动力学模型**：去噪引导中计算 $L_{\text{ach}}$ 需要对系统动力学和控制器进行闭环微分计算，假设了精确动力学模型的存在（未来需要结合无模型方法）。
*   **时间规约语义限制**：目前主要针对 MA-STL-A（异步 STL），智能体在时间步上允许轻微延迟以优先保障安全，暂未直接支持严格同步的接续时序关系（MA-STL 原版全集）。
*   **推理计算开销**：虽然比 MILP 快数倍（~1s），但相比端到端直推式 GNN 模型（<0.1s），扩散去噪采样过程仍有一定延迟，实时性有待进一步通过快速扩散采样算法提升。
